## Данные

918 записей, 23 уникальных направления, 0 повторяющихся ID. ID — детерминированный SHA-256 от номера и исходного названия (первые 16 hex символов); локальное редактирование названия не меняет ID. Все базовые записи: unknown / needs_review, неизвестные даты, ссылки, формат и стоимость — null. Уровень приказа не выводится из названия и не добавляется.

Excel ранее прочитан из C:/Users/user/Downloads/Список олимпиад.xlsx, использовался единственный общий лист «Все мероприятия». Во время этой задачи исходного файла по прежнему пути не оказалось. JSON создан из сохранённой в olympiads.html полной выгрузки того же общего листа. Новую сверку с Excel выполнить невозможно без книги. Текст сохранён без исправления OCR, тематические листы не добавлялись. Источник и год установлены по заданию пользователя.

## Возможности

Каталог через fetch, 24 записи на страницу, поиск и фильтры (направление, аудитория, проверка), URL-параметры, карточка с обозначением неизвестных данных. Сохранение и удаление из сохранённых. Локальная демо-сессия четырёх ролей, без обещаний безопасной авторизации.

Студент: профиль, интересы, первые 24 рекомендации по направлениям, участия, статусы, результаты, место, заметки. Допуск не подтверждается.

Преподаватель: стартовая вымышленная группа и студент, создание групп и студентов, добавление участия для студента, редактирование статуса, результата, места и заметок.

Организатор: создание черновика, отправка на модерацию, повторная отправка отклонённого предложения, просмотр локального статуса. Модератор: редактирование предложения, одобрение/отклонение, ручная правка названия, направления, аудитории, проверки, дат, URL, формата и стоимости. Одобренные предложения видны в каталоге этого браузера.

Сброс требует подтверждения и удаляет только ключи демо; посторонние данные origin не очищает. Базовый JSON не изменяется.

## Хранение

localStorage: savedCompetitions, competitionOverrides, spoDemoSession, spoDemoProfile, spoDemoParticipations, spoDemoTeacher, spoDemoSubmissions. IndexedDB не применяется: небольшое изменяемое состояние не требует дополнительной подсистемы. Данные привязаны к браузеру и origin, между устройствами не синхронизируются.

Только PHP/MySQL: настоящие аккаунты и серверные права доступа, общая БД, защищённые загрузки, CSV/PDF-импорт и серверная история/транзакции. Эти механизмы не заменены клиентской имитацией. Корневая серверная версия не перемещалась и в этой задаче не редактировалась.

## Запуск и публикация

Из корня: `python -m http.server 8000 --bind 127.0.0.1 --directory docs`, открыть http://127.0.0.1:8000/. Или `php -S 127.0.0.1:8000 -t docs`. Остановка Ctrl+C.

Для проверки subpath: `python scripts/serve-pages.py`, открыть http://127.0.0.1:8766/spo-competitions/.

GitHub → Settings → Pages → Deploy from a branch → main → /docs → Save. Адрес https://USERNAME.github.io/REPOSITORY/. Реальная публикация и push в этой задаче не выполнялись.

Commit/push: новые docs/*.html, docs/.nojekyll, docs/assets/, docs/data/, этот отчёт, README.md, scripts/serve-pages.py, tests/pages-smoke.cjs, tests/pages-extra.cjs. Временные .local-runtime/* не добавлять. Существующие документы в docs остаются на месте и также будут доступны при публикации папки.
