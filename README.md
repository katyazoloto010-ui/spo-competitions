# СПО / возможности — публичная GitHub Pages версия

Статический сайт: HTML, CSS и обычный JavaScript. PHP/MySQL-реализация в корне проекта не изменяется и не требуется для публикации этой папки.

## Структура

```text
index.html                    Лендинг
competitions.html             Каталог с фильтрами и пагинацией
competition.html?id=...       Полная карточка
saved.html                    Сохранённые мероприятия
organizer-demo.html?id=...     Страница программы showcase-концепта
assets/public.css             Общая адаптивная система публичных страниц
assets/public.js              Публичные сценарии
assets/topics.js              Направление → иллюстрация и нейтральное описание
assets/images/competitions/   17 тематических JPG
data/competitions.json        918 официальных записей
data/categories.json          23 направления
data/showcase-competitions.json  8 авторских концептов
tests/public-experience.cjs    HTTP-проверки в браузере
tools/build-content.py         Воспроизводимая генерация showcase и оболочек HTML
tools/image-assets.json        Темы и имена сгенерированных изображений
ui-screenshots/public-landing/ Скриншоты и результат проверок
```

Кабинеты student/teacher/organizer/moderator в виде HTML и старый assets/demo.js сохранены. Они не включены в публичное меню; скрытие меню не является разграничением доступа.

## Главная

Hero с двумя CTA; ближайшие программы коллекции «Практика»; направления с количеством записей; четыре шага участия; редакционная подборка из официального перечня; преимущества сервиса; финальный CTA; проектная информация и footer. Числа рассчитываются из JSON. Рекомендации на главной не персональные.

## Два источника данных

Официальные записи имеют dataType=official. Названия, номера и направления сохранены из прежней выгрузки Excel. Даты, возраст, допуск, формат, стоимость и URL не выдуманы. Все 918 officialUrl пока null. В рамках этого этапа к официальному JSON добавлен только dataType. Ранее внесённые пользователем локальные исправления по-прежнему читаются из competitionOverrides.

Showcase — отдельный JSON с dataType=showcase и ID showcase-*. Восемь полностью вымышленных программ: «Код маршрута», «Языковой мост», «Экономика решений», «Мастерская урока», «Дизайн повседневности», «Наука начинается с вопроса», «Зелёный кампус», «История в кадре». Их организаторы, даты, стоимость и этапы являются авторскими концептами, а не реальными анонсами. Интерфейс называет источник «Коллекция “Практика” · концепт» и отделяет его от официального перечня.

Блок ближайших выбирает до трёх showcase-программ по будущей дате относительно календаря Москвы. Когда сроки всех программ пройдут, появляется честное пустое состояние; даты автоматически не переносятся.

Кнопка организатора для официальной записи использует только абсолютный HTTP(S) officialUrl без userinfo. При отсутствии URL она неактивна с пояснением. При наличии безопасного registrationUrl появляется дополнительная ссылка регистрации. Для showcase переход строится только на organizer-demo.html?id=showcase-*. Официальный ID никогда не открывает фиктивного организатора.

## Заявка и сохранение

Страница showcase-организатора показывает бренд-концепт, описание, сроки, формат, стоимость, этапы, FAQ и проектную информацию. «Подать заявку» открывает модальное окно, которое прямо сообщает, что регистрации нет. Персональные данные не собираются. Можно сохранить интересующее мероприятие; успешная отправка организатору не имитируется.

Сохранённые официальные и showcase-ID используют прежний localStorage.savedCompetitions, переживают refresh и синхронизируют счётчик между вкладками одного origin. При отказе браузера в хранении показана ошибка. Никакого backend API нет.

## Изображения и описания

17 иллюстраций созданы встроенным image_gen, без сторонних фотостоков. Темы: IT, исследования, математика, языки, гуманитарные дисциплины, экономика, педагогика, искусство, дизайн, инженерия, экология, спорт, медиа, музыка, сцена/танец, космос и общее образование. Один тематический образ может использоваться для нескольких близких направлений. Для неизвестного направления — general.jpg.

Изображения экспортированы в JPEG до 960×640 с сохранением композиции. На карточках и в деталях используется object-fit: contain, заданы размеры, изображения ниже первого экрана загружаются лениво. Крупная иллюстрация главной сохранена из существующей серии.

Общий запрос генерации: wide 3:2 editorial illustration, polished premium 3D still life; milky ivory, pale blue, subtle muted gold; matte ceramic and frosted glass; soft daylight; centered composition and generous safe margins; no cropping, words, logos or watermarks. Конкретные сюжеты каждого изображения сохранены в tools/image-assets.json.

Все 23 направления явно сопоставлены иллюстрациям и описаниям в assets/topics.js. Общие описания говорят об области интересов и не подменяют фактические условия конкурса. В деталях официальной записи это поясняется.

## Проверка и запуск

Из папки docs: `python -m http.server 8000 --bind 127.0.0.1`, затем http://127.0.0.1:8000/. Через file:// JSON не загружается. Сервер нужен только при разработке; на GitHub Pages сайт полностью статический.

Браузерные проверки: `node docs/tests/public-experience.cjs` из корня. Зависимость Playwright требуется только для тестов. Если используется модуль окружения, задайте PLAYWRIGHT_MODULE и CHROME_PATH. Тест самостоятельно запускает и останавливает HTTP-сервер на свободном loopback-порту, обслуживает /spo-competitions/, использует отдельный браузерный контекст. Время для проверки ближайших событий зафиксировано на 14.10.2026. Скриншоты и результаты сохраняются в ui-screenshots/public-landing/. Для сверки исходных названий тест также читает сохранённую корневую выгрузку olympiads.html.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /docs. Если содержимое docs размещено в корне отдельного репозитория, выбрать /(root). Сохранить .nojekyll. Внешние пакеты и сборка не требуются. Реальная публикация в этой задаче не выполнялась.

## Что ещё требует наполнения

Подтверждённые сайты организаторов и условия официальных конкурсов пока отсутствуют. В названиях официального списка остаются ошибки OCR. Реальный URL репозитория и контакт проекта не предоставлены: footer ведёт на GitHub как платформу и честно сообщает об отсутствии контакта в проектной информации. Showcase-заявка не является реальной регистрацией.

Изменения этого этапа находятся только в docs/. Для сайта нужны пять публичных HTML, public.css, public.js, topics.js, все используемые изображения, JSON и .nojekyll. Существующий PDF источника нужен для ссылки на приказ. Остальные документы, инструменты, тесты и скриншоты не обязательны для работы посетителя; если публикуется вся docs/, они также доступны.
