# СПО / возможности — статическая GitHub Pages версия

Публичный каталог содержит **30 реальное мероприятие прошедших сезонов**, проверенное по сайтам организаторов, операторов и официальным публикациям 15 октября 2026 года. Это не перечень на 2026/2027 год и не список открытых регистраций. PHP/MySQL-версия не изменена и для этой папки не требуется.

## Данные и источники

- `data/competitions.json`: 30 карточка с читаемым названием, направлением, сезоном, официальной ссылкой и ссылкой на публикацию о сезоне.
- `data/categories.json`: только направления текущей подборки.
- `data/archive/minpros-918-unreviewed.json`: исходные 918 записей сохранены без исправления названий, номеров и направлений; в публичный каталог не загружаются.
- `sources.html`: список первоисточников всех карточек, доступный из footer и главной.

`dataType: official` означает реальные мероприятия по официальным источникам, а не принадлежность к приказу Минпросвещения. `competitionStatus: completed` явно отмечает завершённый сезон. `edition` хранит год или учебный сезон; `academicYear` заполнен только для подтверждённого учебного года. Статус `verified` относится к названию, сезону и источнику, не подтверждает новый набор или допуск конкретного пользователя. `verifiedAt`, `verificationScope`, `sourceUrl`, `audienceNote` фиксируют границы проверки.

Аудитория указана осторожно: СПО, школьники, разные категории либо неизвестно. Для Абилимпикс явно указаны инвалидность/ОВЗ. У регионального конкурса «Студент года» указаны ограничения Санкт-Петербурга. Название «олимпиада школьников» само по себе не использовалось для утверждения допуска студентов СПО. Три трека НТО представлены отдельными карточками и явно названы треками одной олимпиады.

Неизвестные точные даты, стоимость, формат и ссылки регистрации оставлены null. Ссылки ведут на реальные сайты, иногда на официальную публикацию или архивную страницу. Страницы организаторов могут уже описывать следующий сезон; на карточке показано предупреждение об этом. Текущую доступность внешнего сайта нельзя гарантировать.

## Публичные страницы

- `index.html`: hero, прошедшие сезоны, направления, порядок поиска, подборка разных направлений, преимущества, CTA.
- `competitions.html`: каталог, поиск, фильтры, 24 карточки на странице.
- `competition.html?id=...`: подробности, заметный статус завершения, аудитория, источники и официальный сайт.
- `saved.html`: сохранённые пользователем мероприятия.
- `sources.html`: все источники и сезоны.

Статические кабинеты и `organizer-demo.html` сохранены. Восемь вымышленных концептов из `data/showcase-competitions.json` больше не показываются на главной и не рекламируются в каталоге. Они доступны только по прежним прямым ссылкам и в ранее сохранённом. Источник концептов явно обозначен; за реальные мероприятия они не выдаются. Их даты, организаторы и условия вымышлены. Реальной подачи заявки нет.

Сохранение работает в браузере без аккаунта и БД. Старые локальные правки из `competitionOverrides` больше не подменяют проверенный каталог. Старые сохранённые ID не удаляются из хранилища; записи из исключённой OCR-выгрузки в новой подборке не показываются.

## Оформление

`assets/public.js`, `assets/public.css` — общие публичные сценарии и стили. `assets/topics.js` сопоставляет 23 известных направления тематическим иллюстрациям и нейтральным текстам; текущий каталог использует подмножество направлений. Для неизвестного направления — general.jpg. Существующие 17 JPG не менялись. Изображения — иллюстрации тем, а не фотографии реальных мероприятий.

Краткие описания текущих карточек составлены по предмету мероприятия; они не обещают льгот, призов или допуска. Неизвестные поля скрыты.

## Запуск и публикация

Из docs: `python -m http.server 8766 --bind 127.0.0.1`, затем http://127.0.0.1:8766/.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /docs. При публикации содержимого docs в отдельном репозитории выбрать /(root). Сохранить `.nojekyll`. Сборка, зависимости сервера и база данных не нужны. Через file:// загрузка JSON не работает. В этой задаче публикация в GitHub не выполнялась.

## Проверка

`node docs/tests/public-experience.cjs` — существующий браузерный тест, адаптированный к новому каталогу. Для внешнего runtime задаются PLAYWRIGHT_MODULE и CHROME_PATH. Тест запускает собственный сервер на свободном порту, использует отдельный браузер и путь /spo-competitions/.

Результат: **58 PASSED / 0 FAILED / 0 SKIPPED**. Проверены все 30 страницы, ссылки внутри карточек, источники, поиск, фильтры, сохранение, пагинация, ошибки загрузки, мобильное меню и отсутствие горизонтального скролла на 1440/1024/768/390 px. Исходные 918 записей в архиве сверены с исходной HTML-выгрузкой. Скриншоты и результаты: `ui-screenshots/verified-catalog/`.

Внешняя HTTP-проверка: `ui-screenshots/verified-catalog/link-checks.json`. Ответы внешних сайтов зависят от сертификатов, защиты от роботов и доступности сети; это отдельная проверка, не часть 58 локальных тестов. Проверка содержимого источников выполнялась также через веб-поиск и просмотр официальных страниц.

## Служебные файлы

`tools/curate-verified-catalog.py` содержит проверенную подборку и создаёт JSON. Первый запуск сохраняет прежний список из 918 строк в архив; архив не перезаписывается. Повторный запуск заменяет текущие competitions.json и categories.json подборкой из скрипта.

`tools/update-curated-ui.py` — одноразовый сценарий изменения старого интерфейса; повторно запускать не требуется. Старый `tools/build-content.py` относится к предыдущей версии главной: его запуск перезапишет HTML прежними оболочками. Для публикации ни один генератор запускать не нужно.

При публикации всей docs служебные файлы, архивы, документы и скриншоты также станут публичными. Для работы посетителя достаточно публичных HTML, assets, data и .nojekyll. Контакт проекта и URL собственного GitHub-репозитория пока не предоставлены.

### Финальная проверка ссылок

Итоговая подборка: 30 мероприятий, 40 уникальных внешних URL (официальные страницы и источники). 37 адресов ответили HTTP 200 при проверке обычным HTTP-клиентом; оставшиеся три — HTTP 200 при проверке в Chrome. Адреса с 404 и неподходящим содержимым не использованы. Начальная диагностика сохранена отдельно в link-checks-initial.json; финальная — в link-checks.json. Дополнительно проверена конечная ссылка карточки «Росатом» в локальном браузере после замены адреса публикации на страницу результатов олимпиады.

Локальный предпросмотр восстановлен: http://127.0.0.1:8766/. Он обслуживает только docs.
