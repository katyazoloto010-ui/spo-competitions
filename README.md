# Олимпиады и конкурсы — GitHub Pages

Статический сайт для школьников, студентов, учителей и организаторов. Рабочая версия находится в docs; PHP/MySQL в корне не изменены.

## Обновление 16 октября 2026

Публичная часть ориентирована на учебный год 2026/2027. Убраны технические отметки проверки, формулировки «реальные мероприятия», проектные пояснения, служебные ссылки GitHub и акцент только на студентах СПО.

Каталог содержит 30 мероприятий:

- 11 имеют подтверждённый анонс сезона 2026/2027 и ссылку `seasonSourceUrl`;
- 19 — мероприятия для планирования на 2027 год, новый сезон которых пока не подтверждён. Они имеют `seasonConfirmed: false`, `competitionStatus: awaiting_announcement` и видимую подпись «2027 год · анонс ожидается». В подробностях указан ориентир, а не обещание проведения. Выдуманных точных дат нет.

Даты НТО, «Бельчонка», «Высшей пробы» и другие сроки взяты из текущих официальных публикаций. Разные даты финала у предметов не сведены к одному вымышленному дню. У «Технокубка» анонс уже говорит о сезоне 2026/2027, но блок расписания ещё подписан 25/26, поэтому его точные даты не перенесены. Открытая регистрация автоматически не предполагается.

Архив прошлых 30 карточек сохранён в `data/archive/verified-seasons-through-2025-2026.json`. Первоначальные 918 OCR-записей — в `data/archive/minpros-918-unreviewed.json`. Идентификаторы не менялись, чтобы сохранить пользовательские закладки. Год в старом ID является техническим идентификатором, не датой текущего события.

## Фотографии и логотипы

Официальные медиа находятся в `assets/images/official/`. Адреса файлов, страницы происхождения, размеры и типы записаны в `data/official-media.json`; карточки ссылаются на них через `image` в `data/competitions.json`.

Использованы фотографии с «Большой перемены» и премии «Студент года», логотипы мероприятий и их организаторов. Фото прошлых мероприятий иллюстрируют сам конкурс, не выдаются за фотографии будущего сезона. Главная использует фотографию «Большой перемены» с подписью Движения Первых. Источники изображений доступны на странице «Организаторы»; логотипы сохраняют принадлежность соответствующим организациям, наличие файла не означает свободную лицензию или партнёрство с сервисом.

На карточках логотипы вписываются без обрезки, для белых знаков предусмотрен тёмный фон. Неудавшиеся или неподтверждённые изображения не заменяются случайными фотографиями: используется текстовое оформление названия. 3D-иллюстрации больше не используются на публичных карточках и в hero; прежние файлы сохранены.

## Страницы

- `index.html`: главная, текущий сезон, направления, порядок участия, ожидаемые анонсы, описание сервиса для четырёх аудиторий.
- `competitions.html`: поиск, направление, аудитория, фильтр объявленного/ожидаемого сезона, пагинация.
- `competition.html?id=...`: изображение, описание, аудитория, даты, официальный сайт, сохранение.
- `saved.html`: закладки браузера.
- `sources.html`: организаторы и ссылки на источники изображений.

Публичный каталог не подмешивает вымышленные showcase-мероприятия и локальные предложения. Старые showcase JSON и страница программы сохранены для истории интерфейса и не входят в публичную навигацию. Проектные, технические и демонстрационные сведения остаются в документации.

## Запуск

Из docs: `python -m http.server 8766 --bind 127.0.0.1`.
Адрес: http://127.0.0.1:8766/. GitHub Pages: публикация ветки main, папка /docs. Сохранить `.nojekyll`. Сборка и база данных не нужны. На GitHub изменения в этой задаче не отправлялись.

## Проверка

`node docs/tests/public-experience.cjs` запускает актуальный `season-2027.cjs`. При необходимости задать `PLAYWRIGHT_MODULE` и `CHROME_PATH`. Тестовый HTTP-сервер поддерживает SVG, JPEG, PNG и WebP и проверяет путь /spo-competitions/.

Результат: **29 PASSED / 0 FAILED / 0 SKIPPED**. Внутри проверены все 30 карточек, изображения, ссылки организаторов, отсутствие запрещённых служебных фраз и 2025 года в видимом тексте, дата/анонс, фильтры, поиск, закладки и мобильное меню. Шесть публичных маршрутов проверены на 1440, 1024, 768 и 390 px. Скриншоты: `ui-screenshots/season-2027/`.

Старые результаты в `ui-screenshots/verified-catalog/` относятся к предыдущему каталогу архивных сезонов.

## Служебные инструменты

Скрипты `curate-verified-catalog.py`, `update-season-2027.py`, `update-public-season-ui.py`, `update-curated-ui.py` и `build-content.py` использовались на отдельных этапах. Это не обязательный конвейер сборки: повторный запуск старых генераторов может заменить данные и оболочки предыдущими вариантами. Для публикации достаточно готовых файлов docs.

Скрипты `discover-official-media.py`, `discover-media-details.py`, `collect-official-media.py` сохраняют происхождение материалов для редакторской проверки. Автоматически выбирать первое найденное изображение нельзя: среди них встречаются партнёрские знаки, иконки и материалы других мероприятий. Изображения текущих карточек визуально проверены.

Итог по изображениям: 28 карточек с официальными медиа (включая 2 фотографии); у «Волга-IT» и «Студента года в системе СПО Санкт-Петербурга» временно текстовое оформление названия. Получение подходящих изображений с этих сайтов блокировалось таймаутом/HTTP 403. Чужие или вымышленные логотипы не подставлены.
